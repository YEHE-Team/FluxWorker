# FluxWorker

FluxWorker is a desktop AI coding assistant built with Electron + React + TypeScript.

## Tech Stack
- Electron 31
- React 18 + TypeScript
- CodeMirror 6 (multi-language code editor)
- Tailwind CSS
- electron-vite + electron-builder

## Development
```bash
npm install
npm run dev
npm run build
npm run dist:win
```

## Key Components
- AI Agent Engine (src/main/agent/)
- Multi-provider AI support (OpenAI, Anthropic, etc.)
- MCP Protocol Integration
- Security Sandbox
- Sub-agent System
